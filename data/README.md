# Data

This project uses the **EMSCAD / "Real or Fake Job Posting"** dataset (17,880 postings, 866 labelled fraudulent),
originally published by the University of the Aegean and mirrored on Kaggle:
https://www.kaggle.com/datasets/shivamb/real-or-fake-fake-jobposting-prediction

Download `fake_job_postings.csv` and place it here as `data/fake_job_postings.csv`.
The file is not committed to this repository.

Expected shape: 17,880 rows × 18 columns; `fraudulent` sums to 866.
